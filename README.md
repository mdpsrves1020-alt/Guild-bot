### 🌟 Overview
**Free Fire Elite Guild Glory Manager** হলো একটি প্রিমিয়াম টেলিগ্রাম বট, যা ফ্রি ফায়ার গিল্ডের মেম্বারদের গ্লোরি পয়েন্ট, লিডারবোর্ড এবং অ্যাক্টিভিটি ট্র্যাক করার জন্য তৈরি করা হয়েছে। এটি অত্যন্ত সিকিউর এবং শুধুমাত্র গিল্ড মাস্টারের কন্ট্রোলে পরিচালিত হয়।

---

### 💎 Key Features
* **👑 Cyberpunk VIP UI:** আকর্ষণীয় ইমোজি, স্টাইলাইজড বর্ডার এবং ফেন্সি কার্ড ডিজাইন।
* **🛡️ Admin Security Shield:** শুধুমাত্র অনুমোদিত অ্যাডমিন আইডি ছাড়া কেউ মেম্বার বা গ্লোরি এডিট করতে পারবে না।
* **🏆 Interactive Leaderboard:** ইনলাইন বাটন এবং রিয়েল-টাইম টপ ১০ মেম্বারদের র‍্যাঙ্কিং লিস্ট।
* **📊 Live Guild Stats:** এক ক্লিকে টোটাল মেম্বার এবং গিল্ডের মোট গ্লোরি কাউন্ট দেখার সুবিধা।
* **⚡ 24/7 Cloud Ready:** GitHub এবং Render-এর মাধ্যমে খুব সহজেই হোস্টিং করার উপযোগী।

### 🎮 Available Commands
| Command | Description | Permission |
| :--- | :--- | :--- |
| `/start` | বট মেইন মেনু ও অপশন ওপেন করে | All Users |
| `/leaderboard` | গিল্ডের টপ গ্লোরি হোল্ডারদের তালিকা দেখায় | All Users |
| `/status <ID>` | নির্দিষ্ট মেম্বারের প্রোফাইল কার্ড দেখায় | All Users |
| `/addmember <ID> <Name>` | নতুন মেম্বার ডাটাবেসে রেজিস্টার করে | Admin Only |
| `/addglory <ID> <Points>` | নির্দিষ্ট মেম্বারের গ্লোরি পয়েন্ট যোগ করে | Admin Only |
